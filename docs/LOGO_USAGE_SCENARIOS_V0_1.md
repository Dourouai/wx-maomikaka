# 猫咪咔咔 Logo 应用场景规范 v0.1

## 1. 使用目标

让 Logo 在不同尺寸和不同产品触点中保持统一识别，同时避免完整猫咪图形在小尺寸下变脏、变糊或抢占功能按钮的注意力。

Logo 的正式三色以 [LOGO_COLOR_PALETTE_V0_1.md](LOGO_COLOR_PALETTE_V0_1.md) 为准：咔咔橙 `#E97850`、档案奶油 `#F8F0E6`、深咖墨 `#342923`。

## 2. 四类版本

| 版本 | 适用场景 | 组合方式 | 不适合 |
| --- | --- | --- | --- |
| 完整主标 | 启动页、关于页、官网、品牌介绍、海报、合作物料 | 猫咪图形 +「猫咪咔咔」+ `CITY CAT ARCHIVE` | 24px 以下入口、拍照主按钮、密集列表 |
| 图形标 | 应用图标、头像、收藏夹图标、分享缩略图、首页品牌入口 | 仅使用完整猫咪图形 | 需要解释品牌名称的正式物料 |
| 印章标 | 识别结果、档案确认、活动专题、贴纸、成就反馈 | 猫咪图形置于印章/边框语境中，可搭配 `CAT FOUND` | 导航按钮、长期固定的主品牌锁定 |
| 角标标 | 档案卡、猫咪图鉴、照片详情、卡片封面、内容页页脚 | 小尺寸猫咪图形 + 档案编号/等级信息 | 启动页主视觉、单独承担品牌介绍 |

## 3. 产品页面落位

| 页面/触点 | 推荐版本 | 说明 |
| --- | --- | --- |
| 首页 / 品牌入口 | 图形标 + 品牌名 | 保持入口轻量，品牌名只出现一次。 |
| 拍照页 | 相机功能图标 | Logo 不作为快门按钮；拍照页优先让功能明确。 |
| 识别结果页 | 图形标 + 印章标 | 图形标负责品牌识别，印章标负责“已识别/已归档”的结果确认。 |
| 档案列表 / 猫咪图鉴 | 角标标 | 固定在卡片角落，给编号、等级或标签留出主阅读空间。 |
| 档案详情 | 角标标或图形标 | 详情页可使用稍大图形，但不要重复堆叠完整主标。 |
| 关于 / 设置 / 启动页 | 完整主标 | 用于正式品牌介绍和版本信息。 |
| 分享卡片 / 社交缩略图 | 图形标或印章标 | 优先保证缩略尺寸下仍能看清猫咪轮廓。 |
| 线下物料 / 合作展示 | 完整主标 | 使用留白充足的锁定稿，不与等级色块混用。 |

## 4. 视觉规则

- 猫咪主体保持完整：不裁掉耳朵、相机或身体，不在头顶增加额外“毛”线。
- 线条使用统一的深色描边，减少无功能的内部线条；小尺寸优先保留耳朵、眼睛、相机和轮廓。
- 不拉伸、不压扁、不旋转，不添加渐变、阴影、发光或复杂纹理。
- 不把 Logo 直接当作拍照按钮；功能图标和品牌图形分工明确。
- 不让文字、边框或等级色块压住猫咪主体；四周保留安全留白。
- 完整主标中的中英文比例、间距和基线保持锁定，不单独替换字体或随意重排。
- 橙色是品牌识别色；反白版本只用于深色背景，禁止任意换成等级色。

## 5. 最小尺寸建议

| 版本 | 屏幕/数字媒介 | 印刷/线下 |
| --- | ---: | ---: |
| 完整主标 | 宽度 ≥ 160px | 宽度 ≥ 35mm |
| 图形标 | ≥ 32px | ≥ 10mm |
| 印章标 | ≥ 48px | ≥ 15mm |
| 角标标 | ≥ 24px | ≥ 8mm |

低于建议尺寸时只保留图形标，不强行缩放完整主标。
