# C 卡简洁设计风格规则 v0.8

状态：设计评审稿，仅用于确认视觉方向，尚未写入 PSD。

## 1. 风格定位

关键词：植物标本卡、安静、轻复古、低对比、留白。

保留卡牌的识别元素，但不再用多重描边和装饰线堆叠质感。每个元素只承担一个功能：边界负责结构，底色负责层级，文字负责信息，图标负责指标识别。

## 2. 元素保留

- 左上：C 等级小标签，保留浅色底和单主边线。
- 右上：编号牌，保留 `No.` 和编号值，左右内边距保持一致。
- 中部：可替换背景图和透明猫主体。
- 下部：猫名、相遇文案、 MIKA 分数、魅力/机灵/灵气三个指标。

## 3. 视觉简化规则

- 外框只保留一条主边线；不再叠加重复金线。
- 主图只保留一条主边线；取消底部多余横线和装饰角线。
- 编号牌、评分章只保留底色和主边线。
- 名称区只保留一条分隔线，取消两侧叶片装饰。
- 指标区保留三格、两条分隔线和三个独立图标；取消内沿高光、格底线、铆点和角点装饰。
- 阴影只用于主图和卡体的轻微层次，不做明显投影。

## 4. C 配色

| 用途 | 色值 |
| --- | --- |
| 主文字 | `#3D5241` |
| 主边线 | `#6C8F68` |
| 卡面浅底 | `#F9FCEF` |
| 信息区底色 | `#EFF8E3` |
| 高光 | `#FFFFFF`，低透明度 |

颜色统一偏灰绿，避免高饱和金色和深色溢出；其他等级只替换这组主题色，不改变布局。

## 5. 排版与布局

- 画布固定为 720 × 1420 px。
- 主图窗口：`x=54–666`，`y=80–974`。
- 名称与文案左对齐，左基线统一为 `x=104`。
- MIKA 评分章位于右侧，与名称区共享同一信息带，不遮挡标题。
- 指标模块保持三等分，图标在左、分数在右，三格宽度一致。
- 动态编号、猫名、文案和所有分数统一归入一个 L5 动态内容层；固定 C、No.、MIKA 和图标属于母版层。

## 6. PSD 落地前检查

- 先确认本稿的简洁风格和比例。
- 确认后再生成 PSD；只导入有效图层，不建立隐藏的备用细节组。
- 固定图形继续保留对应路径源；动态内容保持可编辑智能对象。
