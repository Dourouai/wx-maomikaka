## 一句话定位

> **「出门遇猫 → 拍照捕捉 → 生成专属卡片」的现实系猫咪收集游戏。**  
> 像 Pokémon GO，但主角是身边真实存在的猫。

---

## 与 CatchCat 的对比定位

| 维度 | CatchCat（参考基线） | 猫咪咔咔（我们） |
|------|---------------------|-----------------|
| 平台 | Android 独立 App | 微信小程序（低门槛）|
| 拍照验证 | 设备端 AI 防作弊 | MVP 先跳过，后期接入 |
| 卡片内容 | AI 生成属性+战力值 | 品种档案+你的照片+小故事 |
| 社交 | 地图+好友+对战 | MVP 先做个人收集，社交后期 |
| 对战 | 有（Alley Clash） | 暂无，专注收集 |
| 核心情感 | 收集+对战 | **记录相遇**（更治愈） |

**我们的差异化**：不做对战，专注「记录每次与猫的相遇」，更像一本**猫咪旅行日记**。

---

## 核心游戏循环

```
出门 → 遇见真实的猫 → 打开 app 拍照
    ↓
AI 验证是真猫（MVP：模拟）
    ↓
「正在识别猫咪品种…」演出动画（1.5秒）
    ↓
卡片翻转揭示：你的照片 + 品种档案 + 稀有度
    ↓
加入图鉴 / 解锁新品种
    ↓
首页进度更新，推动下一次出门
```

## 拍照与验证

### MVP 阶段
- 调用 `wx.chooseMedia` 打开相机
- 跳过 AI 验证，直接进入识别演出
- 识别结果：根据**已拍摄记录**，优先给出「未解锁品种」

### 未来版本
- 接入微信云调用 / 第三方 CV 接口（如 Google Vision、百度AI）
- 设备端检测「是否真实猫咪」防止上传网络图片作弊
- 根据识别到的真实品种特征匹配图鉴条目

### 内容安全（发布前置条件）
- 用户拍摄的图片必须先经过 `security.imgSecCheck`，通过后才能识别、保存或分享。
- 后续增加昵称、备注等用户可发布文本时，必须先经过 `security.msgSecCheck`。
- 内容安全检测失败时采用失败关闭，不允许通过异常流程绕过校验。

## 卡片系统

### 每张卡片 = 这次相遇的完整记录

```
┌──────────────────────────┐
│  [你拍的实拍照片]         │
│                          │
│  阿橘队长  🟠             │
│  品种：短毛橘猫           │
│  稀有度：⭐ N 普通        │
│  特质：霸道 · 护食        │
│                          │
│  2026-09-01 · 上海静安区  │
│                          │
│  「据说它守着这条巷子      │
│    已经三年了……」         │
└──────────────────────────┘
```

### 卡片数据结构

**品种模板（预设60条，只读）**
```js
{
  id: 'cat_001',
  name: '阿橘队长',
  breed: '短毛橘猫',
  rarity: 'N',              // 由品种本身决定，不随机
  trait: ['霸道', '护食'],
  story: '据说它守着这条巷子三年了……',
}
```

**拍摄记录（用户每次拍照动态生成）**
```js
{
  recordId: 'rec_20260901_001',
  catId: 'cat_001',          // 匹配到的品种模板
  photo: 'wxfile://...',     // 用户实拍图（临时路径→需转存）
  capturedAt: '2026-09-01T13:00:00',
  location: '上海·静安区',   // 选填
  userNote: '',              // 用户备注（选填）
  customName: '',            // 用户给这只猫起的名字（选填）
}
```

**图鉴状态（存储在 wx.Storage）**
```js
{
  "cat_001": {
    unlocked: true,
    records: ['rec_001', 'rec_005'],  // 所有拍摄记录
    featuredRecord: 'rec_001',        // 图鉴展示的主图
  },
  "cat_002": {
    unlocked: false,
    records: [],
    featuredRecord: null,
  }
}
```

## 稀有度系统

**稀有度 = 这个品种在街头有多难遇到**，不随机，品种固定。

| 稀有度 | 说明 | 代表品种 |
|--------|------|----------|
| ⭐ N 普通 | 街头常见 | 橘猫、狸花、黑猫 |
| ⭐⭐ R 稀有 | 偶尔能碰到 | 三花、折耳、英短 |
| ⭐⭐⭐ SR 超稀有 | 街头少见 | 布偶、缅因、无毛猫 |
| ⭐⭐⭐⭐ SSR 传说 | 极难相遇 | 异色瞳、特殊花纹、未知品种 |

---

## 图鉴系统

- 共 **60 种猫**（6 大类 × 10 种）
- 未解锁：灰色剪影 + 品种名 + ？
- 已解锁：你的实拍照 + 档案 + 稀有度徽章
- 同一品种重复拍：**保留所有记录**，用户可选「主展示图」

### 6 大品种分类

| 分类 | 品种 | 稀有度范围 |
|------|------|-----------|
| 🟠 橘猫系 | 短毛橘、长毛橘等 | N～SSR |
| ⬜ 白猫系 | 纯白、白底花纹等 | N～SSR |
| 🐾 花猫系 | 狸花、三花、玳瑁等 | N～SSR |
| 🔵 名品系 | 英短、布偶、折耳、缅因等 | R～SSR |
| 🖤 黑猫系 | 纯黑、黑白等 | N～SSR |
| 🌟 传说系 | 无毛、暹罗、异色瞳、未知品种 | SR～SSR |

## 页面规划

```
pages/
  index/         首页
                  └─ 收集进度条（XX / 60）
                  └─ 今日遇见（当天已拍的猫）
                  └─ 附近目击（后期：其他用户的发现）
                  └─ [去拍猫] 主按钮

  camera/        拍照页
                  └─ 全屏取景框（猫爪四角装饰）
                  └─ 快门按钮
                  └─ 拍摄后跳转揭示页

  reveal/        揭示页（核心爽点）
                  └─ 「正在识别猫咪…」loading 演出
                  └─ 卡片翻转动画
                  └─ 稀有度特效（N 无/R 金光/SR 彩虹/SSR 爆炸）
                  └─ [再拍一只] / [看图鉴]

  collection/    图鉴页
                  └─ 3列网格，已解锁彩色/未解锁灰影
                  └─ 稀有度筛选 Tab
                  └─ 进度统计

  card-detail/   卡片详情页
                  └─ 大图（实拍照）
                  └─ 品种档案
                  └─ 历次拍摄记录列表
                  └─ 给这只猫起名 / 写备注
```

## MVP 开发范围

### ✅ 做
- 完整拍照→揭示→图鉴链路
- 60种猫品种数据
- 本地存储（wx.Storage）
- 稀有度特效动画
- 卡片详情 + 历次记录

### ❌ 暂不做
- AI 真猫验证（防作弊）
- 地图/社区功能
- 好友/社交
- 对战模式
- 服务端 / 云数据库
