# 猫咪咔咔｜五档卡框与海报合成资产 v1

当前版本以最后确认的浅色粉彩渐变为准。五档卡框使用同一套几何，只切换配色皮肤：C、U、R、SR、UR。

## 已拆出的背景框

| 文件 | 用途 | 尺寸 |
| --- | --- | --- |
| `card-frame-c.png` | C 卡框底层 | 1060 × 1484 |
| `card-frame-u.png` | U 卡框底层 | 1060 × 1484 |
| `card-frame-r.png` | R 卡框底层 | 1060 × 1484 |
| `card-frame-sr.png` | SR 卡框底层 | 1060 × 1484 |
| `card-frame-ur.png` | UR 卡框底层 | 1060 × 1484 |

这些 PNG 是透明背景卡框，不包含：猫、背景图、等级徽章、编号文字、猫名、相遇文案、咪咔数字、三个指标数字。

场景图透明窗口统一为：

```text
x = 82
y = 78
w = 897
h = 941
圆角半径 = 56
```

## 五档配色

| 等级 | 主渐变 | 线稿/文字气质 | 装饰重点 |
| --- | --- | --- | --- |
| C | 薄荷奶油 → 暖米白 | 柔和苔藓绿 | 取景框/街角感 |
| U | 雾蓝紫 → 薰衣草奶油 | 灰紫蓝 | 叶片/轻盈感 |
| R | 香槟杏 → 蜂蜜奶油 | 暖金棕 | 四角星光 |
| SR | 蜜桃珊瑚 → 桃白 | 柔和砖红 | 轨道流星 |
| UR | 灰紫蓝 → 淡紫白 | 柔和靛紫与浅金 | 月牙星光 |

## 组合层级

```text
01  card-frame-{level}.png       固定卡框、纸张、信息区和渐变
02  background-image             本次相遇的背景图，按场景窗口裁切
03  cat-image                    小猫抠图；如果没有可靠抠图则并入背景图
04  fixed-elements               等级徽章、编号牌底、MIKA 圆章、三项图标
05  dynamic-text                 编号、名字、文案、咪咔和三个数值
06  export-finish                导出时统一阴影、清晰度和色彩检查
```

## 小程序合成方式

推荐使用一个离屏 Canvas 2D 作为“海报生成器”，页面上的卡片预览和最终导出共用同一份坐标配置：

```text
选择等级 → 选择 card-frame-{level}.png
加载背景图 → 裁切到统一场景窗口
加载猫咪图 → 按主体锚点叠加，或使用完整相遇图
叠加固定元素 → 徽章、编号牌底、MIKA 底、指标图标
绘制动态文字 → 编号、猫名、文案、四个数值
导出图片 → 临时文件 → 预览 / 保存 / 分享
```

## 开发约束

- 五档不能改变任何元素尺寸、坐标、圆角和信息层级。
- 卡框文件只负责“皮肤”，不要把动态文字烘焙进 PNG。
- `100` 只作为设计稿占位；生产态由 Canvas 写入实际整数。
- 卡面顶部只显示 `C / U / R / SR / UR`，不显示中文等级名。
- 卡面不绘制 `/100`、百分号、进度条或指标文字。
- 猫名最多 5 个字；文案最多 50 个中文字符。
- 图片加载失败、文字越界或猫脸被遮挡时，不导出成品卡。

## 当前视觉验收点

1. 五张卡的外框宽度和圆角完全一致。
2. 五张卡的图片窗口大小完全一致。
3. R 使用香槟杏金，不再使用深沉的金棕色。
4. UR 保持浅灰紫，不使用接近黑色的深底。
5. 同一只猫、同一张背景图放入五档后，只能明显感知边框和装饰色变化。
