# C 卡 · 简约杂志封面精修

基于用户选定的第三款设计继续优化，本轮增加单圈等级色边框。

## 本轮设计约束

- 保留原有猫咪照片、咖啡馆场景和满幅照片风格。
- 卡片比例 1:2；照片占比目标约 75%，下方为暖白信息区。
- 外侧只保留一圈鼠尾草绿边框，目标色 `#8FA783`、宽度约卡宽的 0.6%；不叠加双线、浮雕、阴影或金属效果。
- 后续 C / U / R / SR / UR 复用同一边框尺寸和布局，通过边框颜色与等级字母共同区分。其他等级的具体颜色尚未定稿。
- C 为小方形底标，字母居中；右上角编号与左侧等级标使用相同外边距。
- 缩小标题和 MIKA 总分，标题及两行文案左对齐。
- 三个图标统一颜色、线宽与视觉大小；三项指标保持同一基线，不加分隔框。
- 保留全部示例内容：等级、编号、猫名、两行文案、MIKA 总分、魅力／机灵／灵气数值。

## 交付性质

本轮为 PNG 视觉设计稿，不是分层 PSD。图像由内置 imagegen 基于参考图编辑；完整提示词见 [PROMPT.md](PROMPT.md)。实际出图应与上述目标逐项核对，不能将生成位图视为可编辑母版。
