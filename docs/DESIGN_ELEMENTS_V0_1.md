> 本文件是 v0.1 的旧版“纸张/档案”方向，仅保留作历史参考。当前视觉基线以 [软萌相机 UI 风格定义 v2](./UI_STYLE_GUIDE_V2.md) 和 [软萌相机风格板 v2](./UI_STYLE_BOARD_V2.svg) 为准。

> 当前阶段：视觉设计稿
>
> 适用范围：首页、拍照页、结果卡和后续图鉴页。

## 1. 设计关键词

```text
城市漫游 / 手账档案 / 轻收藏 / 温柔观察 / 猫咪纸卡
```

视觉不把猫咪做成“战斗单位”，而是做成用户在城市里收集到的一张张相遇档案。

## 2. 色彩

| 用途 | 色值 | 说明 |
|---|---|---|
| 页面底色 | `#F7F0E6` | 米白纸张 |
| 卡片底色 | `#FFFAF2` | 纸卡、弹窗、标签 |
| 主色 | `#A7472D` | 拍照按钮、重要数字 |
| 主色深 | `#87361F` | 按钮边框、按下状态 |

| 分割线 | `#E6D9CA` | 轻边框和分隔线 |

## 3. 字体层级

- 页面大标题：手写感或宋体感，突出“去遇见一只猫”。
- 模块标题：粗体，保持清晰和稳定。
- 英文标签：全大写、小字号、增加字距，用作档案感信息。
- 正文说明：无衬线字体，保证小屏阅读。

推荐层级：

```text
页面标题：48–54rpx
模块标题：28–32rpx
正文：21–24rpx
英文标签：15–19rpx
辅助信息：17–20rpx
```

## 4. 罐罐组件

罐罐是每日拍照额度，不是咔咔分，也不是猫咪卡片。

### 未使用

```text
实心罐罐 / 主色或黄底 / 可点击拍照
```

### 已使用

```text
空罐或浅灰轮廓 / 降低对比度 / 不可点击
```

### 推荐文案

```text
今日剩余罐罐
还可以拍 3 次
```

三枚罐罐必须同时配合数字展示，不能只依靠颜色传达状态。

## 5. 主按钮

首页只保留一个主按钮：

```text
拍照
```

按钮表现：

- 烧褐色实心底；
- 米白色相机图标；
- 大圆角，但保留轻微手绘不规则感；
- 按下时缩小约 1–2%，并降低透明度；
- 罐罐为 0 时变为浅灰或米色禁用态。

## 6. 首页取景区域

取景区域是首页最大视觉主体，不直接展示复杂数据。

建议元素：

- 纸卡外框；
- 四角取景线；
- 中央对焦点；
- 猫爪或相机小图标；
- 一句观察提示：`保持一点距离，不打扰它`；
- 胶带、虚线、轻微纸张阴影。

空状态：

```text
等待一只猫
轻触这里，打开相机
```

## 7. 底部导航

```text
相遇 / 图鉴 / 我的
```

- 当前页使用烧褐色图标和浅红米色背景块；
- 未选中项使用辅助灰棕色；
- 每个 tab 同时有图标和文字；
- 导航固定在底部，并适配安全区。

## 8. 卡片等级标签

卡片等级和卡面样式分开定义。代码先统一为 `C / U / R / SR / UR`，中文名称、卡面短标签和最终色彩暂不写死，等待评分规则评审后一次性同步到首页、相机页、结果卡和图鉴页。

评分逻辑与数值见 [小猫评分与等级规则 v0.2](./CAT_SCORING_RULES_V0_2.md)。

`AR`、`SAR` 后续可作为特殊插画或卡面工艺标签，不作为等级。

## 9. 结果卡奖励元素

拍照完成后，在结果卡中展示奖励，不在首页领取：

```text
★ CAT FOUND ★

猫咪照片
猫咪名称 / 卡片等级 / 编号

猫爪 +115
咔咔分 +8
```

“猫爪”是经验名称；“咔咔分”是可累计资源名称。

## 10. 设计原则

1. 首页只让用户做一件事：拍照。
2. 罐罐状态必须一眼读懂。
3. 纸张和贴纸只做氛围，不遮挡操作和文字。
4. 猫咪是被记录的真实相遇，不做战斗化表达。
5. 等级体现遇见稀缺程度，不代表猫咪价值高低。
