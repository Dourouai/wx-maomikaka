# 猫咪咔咔 — 相机页视觉稿 v1

> 当前阶段：相机页视觉与交互提案
>
> 本文只定义相机页的视觉状态、拍摄控件和卡片等级标签提案，不涉及代码实现。

## 1. 相机页定位

相机页是一次相遇发生的现场。它需要让用户快速完成拍摄，同时保留一点“观察猫咪”的仪式感。

核心动作只有一个：

```text
按下快门
```

## 2. 视觉方向

从首页的米白手账切换到更沉浸的深色“猫咪观察仪”：

- 深可可色取景背景，减少环境干扰；
- 奶油白和珊瑚色作为控件高光；
- 快门按钮做成软软的猫爪/猫鼻子形态；
- 取景角、贴纸、星星和小对话框增加可爱感；
- 不做冷冰冰的摄影软件术语，改成温柔、短句式提示。

## 3. 页面布局

```text
关闭 / 今日剩余罐罐
          ↓
猫咪观察提示
          ↓
沉浸式取景框
          ↓
观察提醒 / 对焦状态
          ↓
猫爪快门
```

### 顶部

- 左侧：关闭按钮；
- 中间：`CAT SPOTTER · 02` 和一句拍摄提示；
- 右侧：`今日罐罐 2 / 3`；
- 顶部信息使用半透明贴纸，不遮挡相机画面。

### 取景框

- 保留四角取景线和中央对焦点；
- 增加两个轻量状态标签：`猫咪观察区`、`不使用闪光`；
- 底部显示 `保持一点距离，不打扰它`；
- 猫咪进入中央区域时，对焦框可以短暂变成珊瑚色。

### 快门区

- 快门按钮为最大控件；
- 外圈为奶油色，内圈为珊瑚色；
- 中心使用猫爪或猫鼻子图形；
- 按下时缩小、闪一下，并触发轻微震动；
- 快门旁只保留一句说明：`轻轻按下`。

## 4. 相机页状态

### 准备拍摄

```text
今日罐罐 2 / 3
让它出现在框里
[猫爪快门]
```

### 对焦中

```text
正在看清它……
```

对焦框从米白变成珊瑚色，快门保持可用但防止连续触发。

### 拍摄处理中

```text
正在收下这次相遇
本次使用 1 个罐罐
```

快门进入 loading，不能重复创建任务。

### 相机权限异常

```text
需要打开相机
允许相机权限，才能记录这次相遇
[去设置]
```

错误状态使用奶油色小卡片覆盖在取景框上，不直接展示系统错误码。

## 5. 交互规则

- 点击关闭按钮：返回首页；
- 点击快门：提交一次拍摄任务，并立即扣除 1 个罐罐；
- 连续点击快门：只允许创建一个任务；
- 识别不是猫或图片不合格：罐罐不返还，不发奖励，展示失败原因；
- 服务端、存储、模型或结算异常：返还罐罐，展示异常提示；
- 识别成功：进入识别结果卡并发放奖励；
- 结果卡完成后返回首页，首页更新剩余罐罐数量。

## 6. 卡片等级标签候选 A

本版把标签做成更可爱的“猫咪角色贴纸”，不再使用生硬的稀有度术语：

| 代码 | 等级名称 | 卡面标签 | 视觉印象 |
|---|---|---|---|
| C | 路过猫 | 路过 | 轻轻从街角经过 |
| U | 探头猫 | 探头 | 从角落偷偷出现 |
| R | 回眸猫 | 回眸 | 难得回头看你一眼 |
| SR | 星光猫 | 星光 | 出现时自带高光 |
| UR | 彩蛋猫 | 彩蛋 | 城市里隐藏的惊喜 |

卡片上使用短标签，详情页再展示完整名称：

```text
C · 路过
R · 回眸
UR · 彩蛋
```

这组名称是视觉候选方案，待确认后再同步到玩法主文档。
