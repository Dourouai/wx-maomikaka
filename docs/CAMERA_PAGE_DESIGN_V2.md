# 猫咪咔咔 — 相机页视觉稿 v2

> 旧版候选稿：本文件保留作过程记录。当前软萌相机视觉基线以 [UI 风格定义 v2](./UI_STYLE_GUIDE_V2.md) 和 [UI 风格板 v2](./UI_STYLE_BOARD_V2.svg) 为准。

> 当前阶段：相机页视觉与交互提案
>
> 本稿只定义相机页的视觉状态、拍摄控件和等级标签候选，不涉及代码实现。

## 1. 这次优化的方向

上一版的深色“观察仪”有一点像专业相机，仪式感够了，但软萌感不足。本版改成 **奶油贴纸相机**：像拿着一台装满猫咪贴纸的小相机，轻、软、亲近。

- 主背景：奶油白 + 云朵紫 + 薄荷绿；
- 取景框：圆角、虚线、贴纸角标，不使用硬朗的黑色边框；
- 快门：奶糖珊瑚色猫爪按钮，成为页面唯一最强动作；
- 提示：全部改成短句和拟人化语气，例如“它在这里”“轻轻按下”；
- 罐罐：做成可数的胶囊，不做复杂任务、进度或商城信息。

## 2. 相机页结构

```text
返回 / 今日罐罐 2 / 3
          ↓
       正在找猫
          ↓
      软萌取景框
          ↓
   它在这里 · 保持一点距离
          ↓
      猫爪快门
```

### 顶部信息

- 左侧：返回按钮，只保留一个动作；
- 中间：`正在找猫`，下面用小号英文 `CAT SPOTTER` 做品牌识别；
- 右侧：`今日罐罐 2 / 3`，剩余数量始终可见；
- 不把“猫爪、咔咔分、等级”放进拍摄页，避免用户在拍摄时分心。

### 取景区

- 取景框采用奶油白描边和圆角虚线；
- 左上角：`正在找猫`；
- 右上角：`不打扰模式`，默认关闭闪光；
- 猫咪进入画面中央时，对焦圈短暂变成珊瑚色，并出现一颗小爱心；
- 底部提示：`它在这里 · 保持一点距离`；
- 贴纸只做环境装饰，不遮挡猫咪主体。

### 快门区

- 中央是猫爪快门，外圈奶油白、内圈猫爪珊瑚色；
- 点击后缩小 96%，闪一下白光，轻微震动；
- 快门下方说明本次消耗：`会使用 1 个罐罐`；
- 两侧只放低优先级控件：相册预览、闪光关闭。

## 3. 相机状态

### 准备拍摄

```text
今日罐罐 2 / 3
它在这里
[猫爪快门]
```

### 对焦中

```text
正在看清它……
```

对焦圈变为珊瑚色，快门短暂锁定，防止连续创建拍摄任务。

### 拍摄处理中

```text
正在收下这次相遇
本次使用 1 个罐罐
```

提交后罐罐先减 1；识别成功进入揭示结果卡，识别未通过照常扣除但不发奖励，服务异常才返还罐罐。

### 没有罐罐

```text
今天的罐罐用完啦
明天 00:00 再来找猫
```

快门进入低饱和禁用态，仍可查看相册和已获得卡片，但不能创建新的拍摄任务。

### 相机权限异常

```text
先让相机醒过来
打开相机权限，才能记录这次相遇
[去设置]
```

使用页面内的奶油卡片解释原因，不展示系统错误码。

## 4. 等级标签候选 B

这版不再用“稀有、传说”这类偏卡牌术语，而是把等级写成一次相遇逐渐变特别的过程。代码仍然保留 C / U / R / SR / UR，方便后续做数值和接口；用户看到的是短标签。

| 代码 | 完整称呼 | 卡面短标签 | 感觉 |
|---|---|---|---|
| C | 路过喵 | 路过 | 今天刚好遇见 |
| U | 探头喵 | 探头 | 它偷偷看了你一眼 |
| R | 对视喵 | 对视 | 你们真的碰上目光 |
| SR | 心动喵 | 心动 | 这一眼会记很久 |
| UR | 天选喵 | 天选 | 像被城市特别选中 |

卡片上只显示短标签：

```text
C · 路过     R · 对视     UR · 天选
```

> 候选 B 仍待确认。确认后再同步到首页、卡片揭示页和数据库枚举，不在本阶段改代码。

## 5. 视觉组件清单

| 组件 | 视觉设定 | 交互反馈 |
|---|---|---|
| 今日罐罐胶囊 | 奶油底、珊瑚数字、圆角胶囊 | 提交拍摄后数字减 1；服务异常时返还 |
| 取景框 | 云朵紫/薄荷绿底、奶油虚线框 | 识别到猫时出现心形对焦 |
| 猫爪快门 | 猫爪珊瑚色 + 奶油外圈 | 缩小、闪光、轻震 |
| 观察提示 | 圆角贴纸，短句 | 随状态切换，不堆信息 |
| 等级标签 | 五种低饱和糖果色 | 与结果卡等级颜色一致 |
| 装饰贴纸 | 爱心、星星、鱼干、猫耳角 | 只做氛围，不承担功能 |
