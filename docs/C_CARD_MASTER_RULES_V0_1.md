# 猫咪咔咔 C 卡｜母版规则与优化方向 v0.1

## 1. 这张卡表达什么

C 卡是一次真实的城市猫咪相遇记录，不是战斗卡，也不评价猫咪的价值。画面重点是「猫咪 + 它所在的环境」，相框只负责承载信息和等级识别。

本版只优化 C 卡，其他等级暂不跟随修改。C 确认后，其他等级复用同一套坐标和组件，只替换颜色与等级字母。

## 2. 不可变的版式规则

| 项目 | 固定规则 |
| --- | --- |
| 画布 | 720 × 1420 px |
| 卡片外轮廓 | x=10，y=6，w=700，h=1408，圆角 34 |
| 场景图窗口 | x=54，y=80，w=612，h=834，圆角 31 |
| 编号牌 | x=385，y=80，w=278，h=79 |
| 等级标签 | 固定左上位置，标签本体不移动、不缩放，只显示 `C` |
| 信息区 | x=55，y=914，w=610，h=471 |
| 咪咔徽章 | 中心约为 (604, 1009)，大小固定 |
| 指标模块 | x=55，y=1195，w=610，h=170 |
| 底部内侧横线 | 不绘制、不导出；只保留必要的外框结构和指标模块边界 |

五档母版不能因为等级不同而改变卡片宽高、图片窗口、上下间距、标签大小、分数牌或指标模块位置。

## 3. 图层契约

| 层 | 内容 | 生产时是否替换 |
| --- | --- | --- |
| L1 | C 色纸、外框底、信息区底纸、纸张高光 | 否 |
| L2 | 生成的无猫环境背景 | 是 |
| L3 | AI 单独生成的透明猫 PNG | 是 |
| L4A | 独立 C 等级标签，固定坐标 | 可单独替换 |
| L4 | 场景窗口边线、编号牌、咪咔底、指标格和三个图标 | 否 |
| L5 | 编号、猫名、文案、咪咔、魅力、机灵、灵气 | 是，由 Canvas 绘制 |

L4A 必须是独立素材，既提供固定画布坐标版 PNG，也提供透明裁切版 PNG 和对应 SVG / JSON 路径源。标签内不放中文等级名称。

## 4. 文字规则

红框信息区的宠物名和相遇文案统一左对齐，共用固定左边缘：`x=104`。

- 宠物名最多 5 个字；默认占位：`桃桃晒太阳`。
- 相遇文案最多 50 个中文字符；建议分成 2–3 行。
- 咪咔、魅力、机灵、灵气均为 0–100 整数；设计稿统一使用 `100` 占位。
- 顶部编号保留 `No.` 与唯一编号；编号不参与文字左对齐规则。
- 指标区只显示图标和数值，不显示「魅力 / 机灵 / 灵气」文字。

## 5. C 版视觉规则

C 不是“灰暗的低等级卡”，而是轻、自然、容易亲近的日常相遇档案。

- 主色：薄荷奶油 + 温柔鼠尾草绿。
- 信息区：暖米白，保证深色文字清晰。
- 边框：低饱和绿，使用上下轻微渐变，避免厚重深色边线。
- 高光：只放在外框上沿、标签内沿、编号牌和指标模块边缘，不能溢出卡片或图片窗口。
- 标签：与其他等级保持同一外形、同一位置、同一尺寸；C 只通过绿色色板和字母区分。
- 猫咪与背景占据主要视觉权重，装饰不能抢过主体。

## 6. 合成顺序

```text
L1 C 底纸
→ L2 背景图（场景窗口内裁切）
→ L3 透明猫主体
→ L4A C 等级标签
→ L4 固定装饰
→ L5 动态文字与数值
→ 导出 PNG
```

L2、L3 使用同一场景窗口裁切；L4A、L4 只使用固定几何；L5 不把动态字段烘焙进固定素材。

## 7. 验收标准

- C 版卡片仍为 720 × 1420，所有锚点与 R 基准一致；
- 宠物名和文案左边缘一致，且不碰到咪咔徽章；
- C 标签可以单独隐藏、替换和导出；
- 卡片底部红框标出的多余横线不存在；
- 边框高光只在卡片内部，不出现溢色；
- L2 / L3 替换图片后，不需要重新调整 L4A、L4、L5 的坐标；
- C 确认后再复制到 U / R / SR / UR，不在确认前批量改变其他等级。
