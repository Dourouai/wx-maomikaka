# 猫咪咔咔 — 街角猫档案设计元素 V5

> 类型：视觉方向稿 / UI 设计基线
>
> 本稿只定义界面元素和页面气质，不修改小程序代码，也不替代玩法规则。

## 1. 视觉定位

**像一本随身携带的街角观察手册，把每一次拍猫变成一张有编号的相遇记录。**

英文副标题：`CITY CAT ARCHIVE`

关键词：

`纸张`　`街拍`　`印章`　`留白`　`轻仪式感`

这版以 AI 生成稿中的“纸本档案 + 真实街景 + 深色相机镜头”为主轴。可爱来自细节和语气，不靠满屏贴纸或游戏化面板堆叠。

## 2. 视觉母版

| 元素 | 设计定义 |
| --- | --- |
| 页面底 | 米白纸张 + 低对比点阵，像观察记录本 |
| 主色 | 砖红，承担拍照、选中、奖励和印章 |
| 辅色 | 苔藓绿、旧纸黄、淡粉，用于成功、稀有和背景分层 |
| 文字 | 大号中文标题建立气质，小号等宽字做档案信息 |
| 图片 | 真实街景和猫咪照片优先，插画只做空状态与装饰 |
| 形状 | 纸卡、取景框、圆形镜头、档案标签；减少连续胶囊 |
| 装饰 | 点阵、裁切角、虚线、印章、手写短注释 |

## 4. 字体和层级

| 层级 | 字体 | 建议 |
| --- | --- | --- |
| 页面大标题 | `Songti SC` / 系统衬线 | 30–42 px，字重 600，允许单行大留白 |
| 结果标题 | `Songti SC` / 系统衬线 | 22–28 px，强调猫咪名字和故事感 |
| 界面正文 | `PingFang SC` / 系统无衬线 | 13–16 px，保持易读 |
| 档案信息 | `SFMono-Regular` / `Menlo` | 9–11 px，大写、字距 0.16em |
| 按钮 | 系统无衬线 | 13–15 px，中等字重 |

文案短而轻：使用“去遇见”“收下这次相遇”“明天再来”，避免“任务”“捕捉”“失败惩罚”等词。

## 5. 形状和排版

- 基础网格：8 px；点阵间距：16 px。
- 页面外边距：移动端 20 px；卡片内边距：16–20 px。
- 普通纸卡：12–18 px 圆角；结果卡可以使用 20–24 px 圆角。
- 主要操作：圆形镜头或宽纸按钮，不同时出现两个一级按钮。
- 边框：1 px `line`；重点区域可以用 2 px 白色取景线。
- 阴影：`0 14px 28px rgba(51, 40, 36, .10)`，只表达纸张层叠。
- 允许装饰纸片轻微旋转 `-2deg ~ 2deg`，功能控件保持规整。

## 6. 元素图标语言

图标统一使用“粗线、圆角、少细节”的观察工具语气：

| 图标 | 语义 | 视觉形态 |
| --- | --- | --- |
| 猫爪 | 猫爪、经验、主行动 | 四个肉垫 + 圆掌，砖红填充 |
| 罐罐 | 今日拍照额度 | 小罐轮廓；未使用填色，已使用留空加号 |
| 镜头 | 拍照入口 | 同心圆 + 中心小点 |
| 取景角 | 正在观察 | 四个裁切角，不使用完整相框 |
| 印章 | 已记录 / 结果确认 | 圆章或不规则椭圆，允许轻微倾斜 |
| 档案编号 | 猫咪唯一记录 | `NO.0042` 等宽小字，不承担总量 |
| 心形星点 | 气氛反馈 | 只在结果揭示或空状态出现 |

线宽建议 1.8–2.2 px，所有图标最小触控区域为 44 × 44 px。

### 6.1 猫爪图标

- 语义：经验、成长、等级进度。
- 形态：四个圆润肉垫 + 一个完整掌心，使用实体填充，不画成复杂爪痕。
- 颜色：砖红主色；在等级进度中可以使用砖红到珊瑚色的渐变。
- 使用位置：结果奖励、我的页面等级、拍照主快门。
- 关键词：亲近、成长、收下了一次相遇。

### 6.2 咔咔图标

- 语义：拍照获得的咔咔分，来自相机快门“咔咔”声。
- 形态：圆形快门光圈 + 中心小点 + 两组轻微闪光角标，和猫爪保持明显区分。
- 颜色：旧纸金作为底色，墨黑作为图形；特殊奖励可以叠加砖红。
- 使用位置：结果奖励、咔咔分变化、后续兑换或成就入口。
- 关键词：按下、定格、记录、获得。

### 6.3 五级卡面主题与配色

五级主题描述“这次相遇有多特别”，不代表猫咪本身有高低之分。卡面统一采用纸卡结构，通过颜色、边框、符号和少量动效拉开层级；不使用皇冠、火焰或战斗符号。完整卡片规则见 [相遇卡规则与五级卡面样式](./CARD_SYSTEM_V0_1.md)。

| 代码 | 视觉主题名 | 图标概念 | 主色 | 辅色 |
| --- | --- | --- | --- | --- |
| C | 薄荷留影 | 取景角 + 小圆点 | `#DCEAD8` | `#52745C` |
| U | 云朵探头 | 两片小叶 + 探头弧线 | `#E3DDF2` | `#75668A` |
| R | 蜜糖闪现 | 四角小星 + 纸箔边 | `#F7E2AD` | `#A66E2C` |
| SR | 珊瑚星轨 | 星轨弧线 + 爱心星点 | `#F5D4D4` | `#B9544A` |
| UR | 月光神隐 | 月轮 + 星点 + 猫爪印 | `#40304E` | `#F2C671` |

视觉主题名只是卡面设计名称，不是最终中文等级标签。代码若从 `C` 改成 `N`，只替换代码，不改变薄荷留影主题。

图标使用规则：

- C、U 以自然形态和低饱和色为主，保持轻松；
- R 用一到两颗四角星作为“难得一见”的记号；
- SR 用星轨和珊瑚色表达短暂高光；
- UR 使用夜幕紫和月光金形成最高辨识度，但保留奶油白照片区；
- 颜色用于标签、边缘和少量高光，不覆盖猫咪照片。

## 7. 核心组件

### 7.1 今日罐罐

固定文案结构：

```text
今日剩余罐罐
● ● ●   3 / 3
```

状态必须同时依靠图标和数字表达：

- `3 / 3`：三个罐罐都亮起，拍照入口可用；
- `2 / 3`、`1 / 3`：已使用的罐罐变为空心；
- `0 / 3`：快门禁用，显示“明天再来遇见新的猫咪”。

### 7.2 首页镜头

首页最大的视觉对象是深色镜头，不是信息卡片。镜头下方只保留一句动作提示和一个拍照按钮：

```text
去遇见一只猫
带上罐罐，去街角走走吧
```

### 7.3 结果揭示卡

固定信息顺序：`CAT FOUND` → 猫咪 + 背景场景图 → 名字/等级 → `猫爪 +130`、`咔咔分 +11` → `加入图鉴`。

“猫爪”是经验名称，“咔咔分”是可累计资源名称。奖励在结果页自动结算，不需要额外领取。

### 7.4 图鉴卡片

图鉴采用开放式列表，不写死 `12/45` 或 `12/60`。使用：

```text
图鉴
已发现 12 只
```

每张卡优先展示照片、猫咪名字、等级短标签和档案编号。再次遇见同一只猫，进入该猫档案下的相遇记录。

## 8. 页面分工

| 页面 | 第一问题 | 主视觉 |
| --- | --- | --- |
| 相遇 | 今天还能拍几次？ | 大镜头 + 罐罐状态 |
| 拍照 | 怎么不打扰地拍下它？ | 真实街景 + 取景角 + 猫爪快门 |
| 结果 | 这次遇见得到了什么？ | 猫咪档案卡 + 奖励揭示 |
| 图鉴 | 我遇见过哪些猫？ | 照片网格 + 动态档案 |
| 我的 | 我的相遇留下了什么？ | 等级进度 + 统计 + 最近记录 |

底部导航固定为：`相遇 / 图鉴 / 我的`。

## 9. 本版明确不做

- 不使用“藏品”作为页面名称，统一使用“图鉴”。
- 不预设固定猫咪总数。
- 不把等级颜色做成战斗力或价格标签。
- 不在首页堆叠图鉴总进度、排行榜和复杂任务。
- 不让英文承担关键功能信息。
- 不在本轮进入 WXML、WXSS 或业务逻辑实现。
