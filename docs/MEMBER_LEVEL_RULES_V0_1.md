# 猫咪咔咔｜用户成长会员等级规则 v0.1

> 状态：首版落地
>
> 本规则描述用户的长期猫咪记录成长，不描述单次相遇卡的稀有程度，也不等同于付费 VIP。

## 1. 两套等级分开

| 类型 | 作用 | 代码 |
| --- | --- | --- |
| 用户成长会员等级 | 记录用户持续遇见、拍摄和收藏猫咪的旅程 | `LV1`–`LV5` |
| 相遇卡等级 | 描述某一张照片里的这次相遇有多特别 | `C` / `U` / `R` / `SR` / `UR` |

会员等级只使用累计的猫爪成长值；不使用品种、图鉴角色稀有度或单张相遇卡等级计算。

## 2. 五级名称与成长值

| 代码 | 等级 | 会员名称 | 起始成长值 | 下一等级所需 |
| --- | ---: | --- | ---: | ---: |
| `LV1` | 1 | 街角新客 | 0 | 300 |
| `LV2` | 2 | 巷口寻猫人 | 300 | 800 |
| `LV3` | 3 | 城市漫游者 | 800 | 1800 |
| `LV4` | 4 | 猫巷探索家 | 1800 | 3600 |
| `LV5` | 5 | 城市冒险家 | 3600 | 当前最高等级 |

名称顺序表达用户从第一次走进街角，到主动探索城市猫咪路线的成长过程。`城市冒险家`不是终局世界观，后续可以继续增加区域、季节或特别身份体系，而不必把它解释成“所有猫咪的终点”。

## 3. 成长值来源

猫爪就是会员成长值的展示名称。

每次有效单猫拍摄成功后，按相遇卡的咪咔获得猫爪：

```text
猫爪 = roundToNearest5(70 + 咪咔 × 0.6)
```

当前范围约为 `+70` 至 `+130`。猫咪不是照片、识别未通过或服务异常时，不增加成长值；重复遇见同一只猫仍然可以获得本次相遇对应的猫爪。

## 4. 进度计算

当前等级进度只计算当前等级区间：

```text
等级进度 =
  (当前成长值 - 当前等级起始值)
  ÷ (下一等级起始值 - 当前等级起始值)
  × 100%
```

达到 `LV5` 后进度显示 100%，不再显示“距离下一等级还差多少”。

示例：

```text
猫爪 520
当前等级：LV2 · 巷口寻猫人
距离 LV3 · 城市漫游者：280
当前等级进度：44%
```

## 5. 数据字段

首版本地记录使用以下字段：

```json
{
  "pawGrowth": 520,
  "memberLevelVersion": "member-level.v0.1"
}
```

其中 `pawGrowth` 是累计猫爪成长值，会员等级由固定规则实时计算，不单独持久化等级结果，避免名称或阈值调整后数据漂移。

## 6. 展示规则

- 我的页面展示当前会员名称、`Lv.1`–`Lv.5`、累计猫爪和到下一等级的差值；
- 结果页展示本次获得的猫爪，避免在拍摄页堆叠成长信息；
- 会员等级不改变猫咪识别、猫咪唯一性向量或相遇卡评分；
- 首版会员等级是成长称号，不绑定付费、商城、排行榜或额外罐罐。

## 7. 后续可扩展

达到 `LV5 · 城市冒险家` 后，未来可以增加不占用主等级的内容：

- 城市、季节或路线勋章；
- 特别观察主题；
- 纪念头像框和个人档案装饰；
- 由真实贡献触发的称号，而不是无限抬高成长阈值。
