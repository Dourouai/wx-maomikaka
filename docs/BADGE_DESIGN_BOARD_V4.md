# 猫咪咔咔 · 街角邮票收藏册

当前主视觉源文件：[BADGE_DESIGN_BOARD_V4.svg](./BADGE_DESIGN_BOARD_V4.svg)

## 视觉方向

这一版把视觉语言彻底改成“猫咪街角邮局 / 收藏邮票卡”，不再使用圆形徽章或六块大面板：

- 深色档案墙作为画布，形成更强的收藏展示感；
- 12 枚勋章拆成独立的竖向邮票卡，拥有打孔边、内页插画、编号、分类和名字牌；
- 三行六组的排版，把初遇、记录、陪伴的叙事节奏做成一张收藏板；
- 珊瑚、蜜糖、紫、薄荷和蓝绿色只负责区分视觉章节，不表达稀有度或战力。

## 源文件约定

- 全部图形和文字都是原生 SVG；
- 12 个图标使用 `<symbol>` 定义，可通过 `<use href="#icon-first-meow">` 等方式复用；
- 卡片外壳为可复用的 `#badge-card-shell`；旧的 `#badge-shell` 保留在 defs 中，方便历史稿兼容；
- 12 枚展示组带有 `data-badge-id`、`data-category` 和 `data-style="postage-card"`；
- SVG `<metadata>` 保存勋章名称、条件和奖励，便于后续脚本读取或拆分。

当前 SVG 是推荐的主视觉稿；V1–V3 保留作历史探索稿。状态与发送规则不在本次视觉稿中表达。
