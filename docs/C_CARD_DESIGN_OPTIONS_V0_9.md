# C 卡三款设计方向 v0.9

本稿只用于视觉评审，三款都沿用同一张 C 卡的主图、文字、评分和三项指标位置，区别集中在边框、信息模块和主题色。

## A｜留白标本

鼠尾草绿、浅色卡面、圆角指标栏。整体最轻，适合做五个等级的统一母版。

## B｜档案票据

米白卡面、棕色文字和细框指标栏。整体更像旧档案票据，信息感最强，装饰最少。

## C｜深框植物

浅灰绿卡面、深森林绿指标栏。对比度最高，三个指标区更突出，适合强调收藏和等级感。

## 共同规则

- 保留 C 标签、右上编号牌、主图、猫主体、猫名、文案、MIKA 分数和三个指标。
- 主图和信息区位置保持不变，方便后续统一成五套等级母版。
- 每个模块最多使用一条主边线；不使用重复金线、角点、铆点和隐藏备用装饰。
- 动态文字和数据最终仍归入一个 L5 智能对象；本稿暂不写入 PSD。
