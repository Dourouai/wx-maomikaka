# 猫咪咔咔 C 卡｜母版设计规则 v0.3

整理日期：2026-09-05。状态：规则与 C v0.3 母版已落地，可进入评审。

本文件在 v0.2 的尺寸、坐标和可编辑性约束上继续冻结：动态文字数据统一为一个顶部智能对象；`C`、`MIKA`、`No.` 仍属于固定母版。v0.3 进一步移除左上角等级标签底形，只保留直接展示的等级字母。

## 0. 本轮冻结口径

本轮先只做 C 卡，先冻结结构，再复制到 U / R / SR / UR。以下规则是后续绘制、拆图层、导出和小程序合成的共同合同：

1. **尺寸不变**：画布固定为 720 × 1420 px；五个等级只改变字母、配色、渐变和高光强弱，不改变任何组件位置、大小或主图窗口。
2. **主图变高**：C 卡主图窗口固定为 `[54,80]–[666,946]`；底部名称、圆章、文案和指标模块仍使用原网格坐标，不因主图变高而整体下移。
3. **母版在下，示例文字在上**：L1 在最底部，L2 背景和 L3 猫主体居中，L4 固定前景在其上，L5 动态文字与数据位于最顶层。
4. **组件可独立开关**：编号牌、MIKA 圆章、指标模块必须是独立组件；指标模块内部再拆成指标容器、魅力图标、机灵图标、灵气图标四组。
5. **文字数据归一层**：会随每张猫卡变化的编号值、猫名、文案、咪咔分数和三个指标分数，合并为 L5 一个可见智能对象；固定的 `C`、`MIKA`、`No.` 不放入 L5。
6. **线和颜色分开**：填色、主描边、内线、高光、阴影分别成实际有内容的图层；所有图形保留原始路径或矢量蒙版。底部多余内侧横线在五套母版中都不保留。
7. **输出可回溯**：PSD 是编辑源；PNG 只用于预览和小程序合成。任何透明素材必须保持 720 × 1420 px、透明外底和统一坐标。

## 1. 设计范围与不变项

先完成 C 卡，作为五个等级的几何母版。C 定稿后，U / R / SR / UR 共用相同画布、轮廓、图片窗口、标签、组件尺寸、文字框、图标路径和坐标；等级差异通过字母、配色、渐变及高光强弱表达。

卡面只设计正面。大主图由无猫背景图与独立猫主体合成，相框负责等级识别和信息承载。顶部等级只显示直接落在主图上方的字母，不增加等级图标、中文等级名或标签底形。

## 2. 固定与动态内容

| 内容 | 归属 | 编辑和替换方式 |
| --- | --- | --- |
| 相框底色、信息区底色 | 固定母版 L1 | 分开的填充层，按等级换配色 |
| 边线、高光、阴影、装饰、编号牌、分数圆章、指标容器 | 固定母版 L4 | 按组件组织，再拆填色、描边和效果 |
| 等级字母 `C` | L4 内独立子组 L4A | 原生固定文字，直接显示；不含标签底形 |
| `MIKA`、编号前缀 `No.` | 固定母版 L4 | 原生可编辑文字，随对应组件管理 |
| 魅力、机灵、灵气三个图标 | 固定母版 L4 | 三个独立矢量图标；卡面不显示指标名称 |
| 无猫背景图 | 动态内容 L2 | 替换图片，按统一主图蒙版裁切 |
| 猫主体 | 动态内容 L3 | 替换透明 PNG，保留原始图片及变换信息 |
| 编号值、猫名、文案、咪咔分数、三个指标分数 | 动态内容 L5 | 统一放在顶部一个智能对象内 |

“文字和数据放在一个图层”指每张卡会变化的文字和数字统一管理；用户已指定为母版的 `C` 和 `MIKA` 保留在固定组件内，`No.` 也随编号牌固定。

## 3. Photoshop 图层结构

主文档从上到下只有五个工作层级，参考组另行隐藏：

```text
L5｜示例文字与数据          [一个智能对象，位于最顶层]
L4｜母版前景组件            [组]
    L4A｜等级字母 C｜直接文字 [固定文字与轻微阴影]
    编号牌｜独立组件组｜含固定 No.
    咪咔圆章｜独立组件组｜含固定 MIKA
    指标模块｜独立组件组
        指标容器｜底色与分隔线
        魅力图标｜独立图层
        机灵图标｜独立图层
        灵气图标｜独立图层
    主图边线
    外框边线
    信息区分隔与装饰
L3｜猫主体                  [可替换智能对象，主图蒙版]
L2｜背景图                  [可替换智能对象，主图蒙版]
L1｜母版底纸                [组，位于工作层最底部]
00｜参考与辅助线            [隐藏，不导出]
```

母版底纸位于底部。需要盖住图片边缘的边线、等级标签和编号牌属于母版前景组件，放在猫与背景上方；二者合起来是固定母版。等级标签收在 L4 内，保持主面板整洁。

### 3.1 动态文字：一个可见层，同时可编辑

L5 使用与主文档同尺寸的嵌入式智能对象，主面板只显示一个条目。双击后可编辑内部的七个文字对象：编号值、猫名、文案、咪咔、魅力、机灵、灵气。

文案使用一个段落文字框自动换行，不逐行拆层。内部保留真正的文字对象及字体信息，不栅格化成唯一编辑源，也不叠放重复的示例文字。

隐藏 L5 后，所有动态示例应同时消失，固定字母、MIKA、No. 和图标仍然存在。生产合成使用真实数据重新绘制 L5，不把示例占位数值叠加在成品上。

### 3.2 母版：先按组件，再分颜色与线条

每个组件使用清楚的中文名称，按实际存在的元素拆分。例如：

```text
编号牌
    固定文字 No.       [文字]
    高光               [形状或带蒙版效果]
    内边线             [形状]
    主描边             [形状]
    渐变填色           [填充＋矢量蒙版]
    阴影               [受蒙版约束的独立效果]
```

底色、主描边、内线、高光和阴影分别可隐藏、调色。不要把不同组件的所有绿色线条并成一个大图层；也不为了凑层数创建空白层。独立图层需有实际可见内容和明确用途。

L1 至少区分外框渐变、内壳、纸面、信息区底色和纸面纹理。L4 内的等级牌、编号牌、圆章、指标模块等，分别按上述结构组织。编号牌、咪咔圆章、指标模块可单独开关/导出；指标模块内部再拆为容器、魅力图标、机灵图标、灵气图标四组。

### 3.3 原始路径与可编辑性

绘制的轮廓、描边、叶片、图标使用原生形状层或绑定矢量蒙版的填充层。修改路径锚点必须直接改变当前可见图形；仅在路径面板保存一条与 PNG 无关的备用路径，不算完成可编辑交付。

圆弧与曲线保留贝塞尔控制点；渐变保留可调色标与方向；固定文字保留文字属性。纸张纹理等像素内容可以单独保留为智能对象，并用蒙版限制范围。位图导出仅用于合成，PSD 源文件保留编辑结构。

## 4. C 卡固定几何

画布为 720 × 1420 px，RGB / sRGB，透明外底。所有坐标以画布左上角为原点；显示、导出放大时统一等比缩放，不能单独拉伸某一等级或组件。

以下轮廓沿用当前母版源文件的基准，后续绘制与验收需对齐这些值：

| 元素 | 固定区域或锚点 |
| --- | --- |
| 卡片外轮廓 | x=10，y=6，w=700，h=1408，圆角 34 |
| 主图窗口 | x=54，y=80，w=612，h=866，圆角 31；下沿固定到 y=946 |
| 直接等级字母 C | 文字锚点约 x=78、y=151，58 px；浅色正文叠一层 x=81、y=154 的深色轻微阴影；无底形 |
| 编号牌 | x=385，y=80，w=278，h=79，圆角 18 |
| 信息区 | x=55，y=914，w=610，h=471；主图下沿与信息纸面有 32 px 的受控重叠 |
| 咪咔圆章 | 中心 (604,1009)，外径 128 |
| 名称与文案 | 共用左边缘 x=104，右侧文字安全边界 x=519 |
| 名称分隔线 | (104,1057) 至 (519,1057) |
| 指标模块 | x=55，y=1195，w=610，h=170 |
| 图标参考中心 | (103,1284)、(306,1284)、(509,1284) |
| 三项数值中心 | (194,1284)、(397,1284)、(600,1284) |

等宽的三项指标格、相同内边距和共同中线必须由同一套参数生成。不能按视觉猜测对每张卡单独挪动。

## 5. 文字与数值排版

下表为本轮 C 卡制作的文字框规范；需在实际字体下检查边界后交付。固定组件位置不随字数变化。

| 字段 | 内容规则 | 排版规则 |
| --- | --- | --- |
| 猫名 | 最多 5 个可见字符；占位“桃桃晒太阳” | 左对齐 x=104；参考字号 45 px，视觉中心 y=978；右边界不超过 x=519 |
| 相遇文案 | 最多 50 个可见字符，含标点 | 左对齐；文字框 x=104、y=1080、w=415、h=99；参考字号 22 px、行高 31 px，最多 3 行 |
| 编号值 | 占位 MK-260903-000013；真实值由业务提供 | 位于固定 No. 右侧；建议安全框 x=444、y=96、w=202、h=47；从 20 px 起按实际字宽适配，保持一行 |
| 咪咔分数 | 0–100 整数，占位 100 | 参考字号 45 px，中心 (604,1026)，与固定 MIKA 分开 |
| 三项分数 | 0–100 整数，均占位 100 | 参考字号 32 px，使用三个固定数值中心；按三位数预留宽度 |

中文沿用宋体方向，字母和数字沿用衬线字体方向；最终交付记录实际字体及字重。设计端与生产端需验证相同字体度量，不能依赖任意默认字体。

文案短时从同一左上角排起，不做垂直居中；长时允许第三行，模块位置不移动。超出字符上限在内容生成或编辑环节处理；字符合规但超出文字框时需重新排版检查，不能悄悄裁掉文字或任意缩成小字。

四个数字只显示数值本身，不带“分”、百分号或“/100”。图标与数值横向排列，按 100 占位检查两者至少留出 16 px 可见间隙。猫名与文案左对齐；编号在自己的牌内排版，圆章与三项数字仍在各自区域居中。

母版只读取并展示咪咔和三个指标，不在设计规则中重新定义权重、等级阈值或编号生成算法。设计占位 100 不表示 C 等级对应实际满分。

## 6. C 卡配色与精致度

以现有 C 色板为制作起点：明亮薄荷绿边框、浅奶油纸面、深鼠尾草绿文字。配色调整在独立填充和描边层完成。直接等级字母使用浅奶油绿正文配深鼠尾草绿偏移阴影，保证在深浅背景上都可读。

| 用途 | 起始色值 |
| --- | --- |
| 外框渐变 | #E4EFD8 → #A9C599 |
| 主纸面 | #F9FCED |
| 信息区浅底 | #F7FBEA |
| 主边线 | #6C8F68 |
| 淡金绿细线 | #BCCD97 |
| 图标 | #527C56 |
| 正文、字母与数字 | #3D5241 |
| 高光 | #FFFFF7，按组件调低透明度 |

精致度来自统一的细描边、顶部及左侧轻高光、浅凹槽阴影与克制的叶片装饰。主轮廓线参考 2 px，内细线与高光参考 1 px；局部光影保持同一方向，低透明度使用。

所有填色和光影需服从各自组件的蒙版。外框深色不得进入信息区内侧，窗口内不得残留母版底色，圆角之外保持透明。既检查外轮廓溢色，也检查内边线以内的错色。

底部删除用户反复标记的独立内侧横线，不补装饰下划线；必要的卡片外轮廓及指标容器边界保留。主图下面不叠加多余横线。

## 7. 图片插槽与合成

背景图不包含猫、卡框、等级牌或卡面文案；猫图是实际带透明通道的主体图。灰白棋盘格只是编辑器的透明提示，不能烘焙进素材。

L2、L3 共用同一主图窗口蒙版。背景等比铺满并裁切；猫等比放置，保证耳朵、爪子和尾巴不因模板而意外截断。猫的位置可按主体构图调整，固定窗口与卡面组件不移动。

合成顺序：

```text
L1 母版底纸
→ L2 背景（主图窗口内）
→ L3 猫主体（主图窗口内）
→ L4 母版前景组件（含 C、No.、MIKA 与图标）
→ L5 动态文字与数据
→ 成品 PNG
```

L4A 只保留直接等级字母文字与轻微阴影，不再输出或叠加任何标签底形。生产端使用本层级顺序和统一坐标配置。

## 9. 验收标准

1. 主图层面板顶部只有一个动态文字智能对象；隐藏后所有动态文字与四个分数一起消失，固定字母、MIKA 和 No. 保留。
2. 双击动态智能对象后可修改文字；逐个隐藏填色、描边、高光、阴影时，只影响相应组件。
3. 用路径工具调整一个图标或边框节点，画面随之改变；没有仅靠备用路径宣称可编辑的栅格图形。
4. 直接等级字母只作为 L4A 固定文字组管理，不存在可见标签底形或重复叠加。
5. 照片孔与卡片外部是真透明；透明背景、深背景和浅背景下都检查内外边缘，无错色、残线或棋盘格残留。
6. 使用五字猫名、接近 50 字的文案及四个 100 检查边界；另用 0、9、99 检查数值对齐。
7. 在 100% 放大检查细线、节点与溢色，在小程序实际显示尺寸检查名字、文案、数字与图标辨识度。
8. 完成 C 卡的版式与图层验收后，再复制统一模板制作另外四个等级。
